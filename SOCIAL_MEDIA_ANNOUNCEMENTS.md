## Reddit Post (r/programming, r/healthIT)

---

**Title:** Introducing Tolvex: A Programming Language for Healthcare Analytics (formerly Medi)

**Body:**

Hi everyone,

I'm excited to share that we've rebranded our healthcare programming language from Medi to **Tolvex**, and released v0.1.6 with comprehensive updates.

**What is Tolvex?**

Tolvex is a programming language purpose-built for healthcare analytics with:
- Native FHIR, HL7, and DICOM support
- Compile-time privacy tracking for HIPAA compliance
- Statistical analysis and ML primitives for clinical data
- Real-time processing capabilities
- Designed to be accessible to clinicians, not just developers

**Why the Rebrand?**

As the project evolved, we realized our scope had grown beyond what "Medi" represented. Tolvex better captures our mission and provides stronger branding for the ecosystem we're building.

**What Changed in v0.1.6:**

- Compiler: `medic` → `tlvxc`
- Package manager: `medipack` → `tvx`
- File extension: `.medi` → `.tlvx`
- Package registry: `formulary.tolvex.dev`
- All tooling and documentation updated

**Example:**

```tlvx
use tolvex::standards::fhir;
use tolvex_stats::mean;

fn analyze_patient_data(patients: Vec<fhir::Patient>) -> f64 {
    let ages = patients.map(|p| p.age());
    mean(ages)
}
```

**Repository:** https://github.com/Tolvex/tolvex  
**Documentation:** https://tolvex.dev/docs  
**License:** MIT/Apache-2.0

We've preserved all historical releases and commit history. Migration from Medi is straightforward—see our [migration guide](https://github.com/Tolvex/tolvex/blob/main/MIGRATION.md).

Would love to hear your thoughts and feedback!
